# Video Game Store Web Application
This project is a small, database-driven web application that simulates an online video game store. It allows user to browse a catalog of video games, add items to a shopping cart, view cart contents, remove items, and complete a checkout process. The project demonstrates fundamental server‑side web development concepts using PHP and MySQL, along with basic MVC (Model‑View‑Controller) design principles. The application focuses on functionality, clean code organization, and practical experience with full‑stack development workflows.

# Project Tasks
- **Task 1: Set up the development environment
- Install a local web server (XAMPP or similar)
- Configure PHP and MySQL
- Create and connect to the video_game_inventory database
- Set up the GitHub repository for version control

- **Task 2: Plan the project
- Define application features (catalog browsing, cart management, checkout)
- Design database schema for products
- Organize files using a basic MVC structure (Model, View, Controller)

- **Task 3: Implement core features
- Display a catalog of available video games
- Add, decrease, or remove products from the shopping cart
- Display cart contents with price calculations
- Implement checkout functionality that clears the cart

- **Task 4: Test the application
- Verify correct database connections
- Test all cart actions (add, remove, update quantity)
- Ensure totals, tax, and shipping calculations are accurate

- **Task 5: Document the project
- Create a comprehensive README file
- Comment code for clarity and maintainability
- Explain application structure and logic

- **Task 6: Finalize and submit
- Clean up and refactor code where needed
- Comment code for clarity and maintainability
- Explain application structure and logic
